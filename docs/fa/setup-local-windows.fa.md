# راهنمای کامل اجرای Aegis Planner روی کامپیوتر (v1.18.0)

این راهنما برای تست آخرین نسخه است. با **PowerShell ویندوز** نوشته شده؛ معادل
مک/لینوکس هرجا فرق دارد آمده است.

---

## پیش‌نیازها
- **Python 3.10 یا 3.11** (نه ۳.۱۳ — برای سازگاری با PythonAnywhere).
  بررسی: `python --version`
- مرورگر مدرن (Chrome/Edge/Firefox). ولت به WebCrypto نیاز دارد و WebCrypto فقط
  روی `localhost` یا HTTPS کار می‌کند — با `127.0.0.1` و `localhost` مشکلی نیست.

---

## گام ۱ — باز کردن زیپ و ورود به پوشه
```powershell
cd C:\path\to\aegis-planner
```
باید فایل `manage.py` را همان‌جا ببینی.

## گام ۲ — محیط مجازی
```powershell
python -m venv venv
venv\Scripts\Activate.ps1
```
اگر PowerShell اجازه نداد:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
venv\Scripts\Activate.ps1
```
مک/لینوکس: `python3 -m venv venv && source venv/bin/activate`

## گام ۳ — نصب وابستگی‌ها
```powershell
pip install -r requirements.txt
```

## گام ۴ — فایل .env
```powershell
copy .env.example .env
```
حالا `.env` را باز کن و برای **اجرای محلی** این‌طور بگذار:
```
DJANGO_SECRET_KEY=یک-رشته-تصادفی-طولانی
DJANGO_DEBUG=True
DJANGO_ALLOWED_HOSTS=localhost,127.0.0.1
PURCHASE_TELEGRAM=@YourTelegramID
```
کلید تصادفی:
```powershell
python -c "import secrets; print(secrets.token_urlsafe(64))"
```

## گام ۵ — دیتابیس و جدول کش  ← مهم
```powershell
python manage.py migrate
python manage.py createcachetable
```
> **`createcachetable` را جا نینداز.** قفلِ ورود و محدودیت نرخ روی کش دیتابیس
> کار می‌کنند؛ اگر این جدول نباشد، هر POST ورود/ثبت‌نام **ارور ۵۰۰** می‌دهد.
> (این دقیقاً یکی از دو ریشه‌ی «ارور ۵۰۰» بود که در v1.13.1 پیدا شد.)

## گام ۶ — ساخت ادمین
```powershell
python manage.py createsuperuser
```
از v1.13.1 سوپریوزر **خودکار تأییدشده** است و پرمیومش **بدون تاریخ انقضا** —
پس بلافاصله می‌توانی وارد اپ شوی.

## گام ۷ — اجرا
```powershell
python manage.py runserver
```
مرورگر: **http://127.0.0.1:8000/**

## ساخت کد دعوت برای تست ثبت‌نام
با ادمین وارد شو → `/panel/invites/` → یک کد بساز → با آن در
`/accounts/register/` ثبت‌نام کن. کاربر عادی بعد از ثبت‌نام به صفحه‌ی
«در انتظار تأیید» می‌رود و باید از `/panel/users/` تأییدش کنی.

## چک‌لیست تست v1.18 (فازهای A تا H)
**A — ورود/ثبت‌نام:** ورودهای موفق پشت‌سرهم نباید ۴۲۹ بدهند؛ ۱۲ ورود ناموفق
باید صفحه‌ی ۴۲۹ فارسی/انگلیسی بدهد. ثبت‌نام موفق → صفحه‌ی «در انتظار تأیید»
(نه ۵۰۰). کارت پرمیوم ادمین باید «بدون تاریخ انقضا» باشد.

**B — موبایل:** با DevTools روی ۳۷۵px: پنل ادمین، فرم تسک، پومودورو، هدر در
حالت انگلیسی، درگ کانبان با لمس، و long-press روی تسک تقویم.

**C — آفلاین:** اپ را آنلاین باز کن → DevTools > Network > Offline → رفرش:
باید با رمز باز شود و پیل «آفلاین» بیاید → دو تسک بساز → آنلاین کن → باید
خودکار همگام شود.

**C2 — تقویم:** ماه/هفته/۳روز/روز، دکمه‌ی + شناور در موبایل، دایره‌ی «امروز».

**D — آیکن‌ها:** هیچ ایموجی‌ای در بدنه‌ی اپ نباید باشد؛ mood ژورنال، لیست‌ها،
پروگرس‌بارها و لوگوی جدید را ببین.

**E — تم شخصی:** ستینگ → شخصی‌سازی → تم «شخصی» → شش رنگ را عوض کن؛
ستینگ → حساب کاربری → نام و ایمیل را ذخیره کن.

**F — تسک/تقویم/نوت:** یک «رویداد» بساز (نباید چک‌باکس داشته باشد)، فیلتر
تقویم را در ۴ حالت بچرخان، انتخاب چندتایی تسک‌ها، زباله‌دان گروهی، پوشه‌ی
نوت و خروجی Markdown.

**G — گزارش‌ها:** heatmap سالانه، مقایسه، ساعت‌های تمرکز، تحلیل عادت‌ها،
مود ترکر، و دکمه‌ی پرینت.

**H — فروش:** `/#buy` فرم را پر کن → باید در `/panel/purchases/` بیاید.

## اگر به مشکل خوردی
| نشانه | علت | درمان |
|---|---|---|
| POST ورود ۵۰۰ می‌دهد | جدول کش ساخته نشده | `python manage.py createcachetable` |
| «ارور ۴۲۹» موقع تست‌های پشت‌سرهم | محدودیت نرخ | یکی‌دو دقیقه صبر کن، یا کش را پاک کن |
| ولت باز نمی‌شود / خطای رمزنگاری | صفحه روی IP شبکه باز شده | با `localhost` یا `127.0.0.1` باز کن |
| فونت‌ها پیش‌فرض‌اند | فایل‌های فونت عمداً در ریپو نیستند | `static/fonts/` را با Vazirmatn پر کن |
| صفحه‌ی سفید بعد از آپدیت | Service Worker قدیمی | Ctrl+Shift+R یا DevTools > Application > Unregister |

## اجرا روی گوشیِ همان شبکه (اختیاری)
```powershell
python manage.py runserver 0.0.0.0:8000
```
با `DJANGO_DEBUG=True` هر هاست پذیرفته می‌شود. **ولی** روی `http://<ip>:8000`
ولت باز نمی‌شود چون WebCrypto به بستر امن نیاز دارد — برای تست موبایل از
تونل HTTPS (مثل Cloudflare Tunnel یا ngrok) استفاده کن.
