# سیستم طراحی — پلنر امن v1.4 (فاز ۲)

## پالت جدید (پرمیوم، جایگزین قهوه‌ای/فیروزه‌ای)
- Primary: آبی مدرن #4f8cff (دارک) / #2f6bf2 (لایت)
- توکن‌های معنایی: --primary/--secondary/--success/--warning/--danger/--info/--bg/--surface/--surface-2/--border
- تینت‌های نرم برای badge/banner/hover
- هر ۶۲ تم به‌صورت خودکار توکن‌های معنایی را به ارث می‌برند (بدون بازنویسی)

## مقیاس‌ها
- تایپ: --fs-0..--fs-7 (نسبت ۱.۲)، وزن‌های regular..bold
- فاصله: --sp-1..--sp-12 (پایه ۴px)
- شعاع: --r-xs..--r-xl + --r-full
- سایه/ارتفاع: --sh-1..--sh-4 (تیون‌شده برای دارک و لایت جدا)
- حرکت: --ease/--ease-out + --dur-1..--dur-4

## آیکون‌ها
- ست SVG خطی یکدست (سبک Lucide، stroke=currentColor) جایگزین همه‌ی اموجی چروم
- ۲۲ آیکون در sprite داخلی app.html + ۶ آیکون لندینگ
- رنگ‌پذیر با تم، اندازه یکدست، بدون وابستگی خارجی، CSP-safe

## کامپوننت‌ها (ارتقا روی کلاس‌های موجود)
- دکمه‌ها: سلسله‌مراتب واضح (primary گرادیانی / ghost / danger)
- ورودی‌ها: فیلد یکدست با فوکوس رینگ
- کارت/پنل: ارتفاع نرم، border مویی
- دیالوگ: backdrop blur + انیمیشن ورود
- badge/toast/seg/sidebar/topbar: همه با توکن‌های جدید

## لندینگ
- کپی انسانی و متقاعدکننده (فا/EN)
- هیرو با گرادیانت متنی، trust strip، شمارش معکوس
- کارت‌های ویژگی با آیکون SVG و hover لیفت

## دسترس‌پذیری/حرکت
- reduced-motion برای همه‌ی انیمیشن‌ها
- فوکوس رینگ یکدست، aria-label روی دکمه‌های آیکونی چروم
